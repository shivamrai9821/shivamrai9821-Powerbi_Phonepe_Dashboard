# PhonePe Transaction Analytics Dashboard

## Project Overview

The PhonePe Transaction Analytics Dashboard is an interactive Power BI project designed to analyze digital payment transactions, user activity, payment performance, and financial services.

The dashboard transforms raw transaction data into meaningful business insights using interactive visuals, KPIs, filters, and time-based analysis.

## Objectives

* Analyze overall transaction performance
* Track transaction volume and transaction amount
* Understand successful and failed transactions
* Analyze user activity and demographics
* Compare different payment services and transaction types
* Identify transaction trends over time
* Analyze money transfers, recharges, bills, loans, and insurance

## Key KPIs

* Total Users
* Total Transactions
* Total Transaction Amount
* Successful Transactions
* Failed Transactions
* Transaction Success Rate
* Average Transaction Value

## Dashboard Analysis

The dashboard provides analysis of:

* Transaction trends over time
* Payment status
* Service-wise transactions
* Transaction types
* Money transfers
* Recharge and bill payments
* Loan transactions
* Insurance transactions

## Key Insights

* **Transaction performance:** The dashboard provides a clear view of transaction volume, transaction value, and payment success/failure, helping identify overall payment performance.

* **Service-wise behavior:** Analysis of services such as **Recharge & Bills, Money Transfer, Loans, and Insurance** helps identify which services contribute most to overall transaction activity.

* **Payment failure analysis:** Failed transactions can be analyzed by service and failure reason, helping identify areas where payment performance can be improved.

* **User & transaction trends:** Time-based and user-level analysis helps identify transaction patterns and changes in customer activity over the selected period.

* **Business decision-making:** Interactive KPIs, filters, and visualizations enable stakeholders to quickly compare services, monitor performance, and identify areas requiring attention.
